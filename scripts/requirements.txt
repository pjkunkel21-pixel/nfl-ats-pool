# fetch_lines.py uses only the Python standard library.
#
# The default path (sportsbook lines via ESPN's scoreboard) needs nothing else.
#
# Only the optional --circa path, which OCRs the Circa Sports Million contest
# PDF, needs two command-line programs on the PATH:
#   pdftoppm   (poppler-utils)  -- renders the Circa PDF to an image
#   tesseract  (tesseract-ocr)  -- reads the image
#
# macOS:          brew install poppler tesseract
# Debian/Ubuntu:  sudo apt-get install poppler-utils tesseract-ocr
# Windows:        https://github.com/oschwartz10612/poppler-windows/releases
#                 https://github.com/UB-Mannheim/tesseract/wiki
