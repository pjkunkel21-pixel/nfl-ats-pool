Line editor

The fallback for when the Thursday scraper misreads the Circa PDF — or when you just want to set the lines by hand. Nothing here touches the live site until you download the file and commit it.

Paste from the Circa sheet

Open the week's Circa contest spreads PDF, select all the text (or run it through any OCR) and paste it below. Team nicknames and spreads are matched against the schedule, so the order and the surrounding junk don't matter.

Spreads are from the home team's point of view: -3.5 means the home team lays 3½. Type PK or 0 for a pick'em, or leave a cell empty to make that game unpickable.
